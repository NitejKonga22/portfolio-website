# Web Development Project Submission

Three projects matching the assignment:

1. **portfolio/** - HTML/CSS/JavaScript resume portfolio with navbar, contact form, JSON localStorage, admin login/dashboard, timestamps, theme toggle, and Google Apps Script integration starter.
2. **react-contact-cards/** - React SPA with reusable `UserForm`, `UserList`, and `ContactCard` components.
3. **react-like-card/** - React `Card` component using props and `useState` for Like/Unlike.

## Test
Portfolio: open `portfolio/index.html` in Chrome.

React projects: install Node.js, then inside each project run:
```bash
npm install
npm run dev
```

Portfolio demo admin credentials: `admin` / `1234`.


Google Sheets is pre-connected to the deployed Apps Script endpoint supplied by the project owner.
